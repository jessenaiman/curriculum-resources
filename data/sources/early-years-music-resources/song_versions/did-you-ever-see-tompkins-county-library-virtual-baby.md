# Did You Ever See?

Did you ever see a whale, a whale, a whale?
Did you ever see a whale swim this way and
that?
Swim this way and that way and this way and
that way.
Did you ever see a whale swim this way and
that?
Repeat with: crab crawl, dolphin leap, seal
float, shark bite
