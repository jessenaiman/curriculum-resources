# I Can

Tune : Wheels on the Bus
I can make my hands
Go clap, clap, clap,
Clap, clap, clap,
Clap, clap, clap.
I can make my hands
Go clap, clap, clap.
They’re a part of me.
Repeat with:
I can make my feet go stomp, stomp, stomp…
I can make my arms go hug, hug, hug….
